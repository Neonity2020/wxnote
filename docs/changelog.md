# 版本记录

## v0.5.0

- 编辑器不再显示 base64 长串：本地内嵌图折叠为 `editor-local://localN` 短占位，存储态仍保留完整图片
- 状态栏新增「含 N 张本地图」提示
- 字数统计、侧边栏摘要剔除图片语法，不再被 base64 撑爆
- 修复：上传完成后光标跳转到文末的问题

## v0.4.0

- 接入**蜜蜂图床**并设为默认：国内直连、免登录可上传、CORS 开放
- 支持填 API Token 走会员通道（永久保存、无频率限制）
- 上传失败直接透出服务端返回的原因（如限流提示），不再显示笼统错误
- 发布弹窗新增「蜜蜂游客图 1 小时后失效」提醒

## v0.3.0

- 图床改为可配置：本地内嵌 / 自定义接口 / HD-R（代理）/ Telegraph
- 新增图片压缩（长边 1600、WebP q=0.82、JPEG 兜底）
- `pickLink()` 兼容 6 种返回结构，支持自定义字段路径与相对路径补全
- localStorage 配额写失败时告警

## v0.2.0

- 支持图床贴图：粘贴截图 / 拖拽 / 选文件三种方式
- 上传占位符机制（`![图片上传中…](uploading-xxx)`），失败降级本地内嵌

## v0.1.0

- 首版：笔记列表 + Markdown 编辑器 + 公众号排版实时预览
- 一键复制带内联样式的富文本到公众号后台
- 微信视觉规范（`#07C160` / `#576B95` / 677px 正文宽）
- 响应式：三栏 / 抽屉 / 单栏切换
