# 视觉规范

整体基调：**微信自己的样子**——白底、浅灰分割、绿色主操作、胶囊按钮、克制的阴影。不做花哨装饰，因为最终产物是要放进公众号里的文章，界面不应该抢内容的注意力。

## 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--wx-green` | `#07C160` | 主操作（发布按钮、选中态、引用竖线、logo） |
| `--wx-green-dark` | `#06A654` | hover / 按下 |
| `--wx-green-light` | `#E8F8F0` | 选中项背景、绿底浅色块 |
| `--bg` | `#F7F7F7` | 页面底色、编辑区外框 |
| `--panel` | `#FFFFFF` | 卡片、侧边栏、预览纸张 |
| `--text` | `#111111` | 正文与标题 |
| `--text-2` | `#576B95` | 链接色（微信文章正文链接色） |
| `--muted` | `#888888` | 次要信息、时间、摘要 |
| `--border` | `#E5E5E5` | 分割线、输入框描边 |
| `--editor-bg` | `#FAFAFA` | 编辑器底色（比正文区略沉，区分"写"与"看"） |

强调色只有一个。除绿色与链接蓝外不引入第三个彩色，避免界面变花。

## 排版

| 层级 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 预览文章标题 | `clamp(20px, 4vw, 24px)` | 700 | 1.4 |
| 编辑器正文 | 15px（等宽字体） | 400 | 1.8 |
| 笔记标题 | 14px | 600 | 1.4 |
| 笔记摘要 | 12px | 400 | 1.4 |
| 按钮 / 工具 | 13px | 500 | — |
| 状态栏 / 提示 | 12px | 400 | — |

字体族：界面 `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；编辑器 `"SF Mono", Menlo, Consolas, monospace`（让 Markdown 的缩进与表格对齐看得清）。

## 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius` | 10px | 卡片、笔记项 |
| 按钮 | 18px（高 36px 的半高） | 胶囊按钮，微信的典型形状 |
| Modal | 16px | 弹窗 |
| `--shadow` | `0 1px 3px rgba(0,0,0,.06)` | 预览纸张的极轻投影 |
| Modal 阴影 | `0 12px 40px rgba(0,0,0,.18)` | 浮层 |

阴影只用来区分层级，不用来装饰。预览纸张的投影要轻到几乎看不见——它模拟的是"一张白纸"，不是"一张卡片"。

## 间距

4 的倍数体系：4 / 8 / 12 / 16 / 24 / 32。列表项内边距 12px，区块间距 16px，页面级留白 24–32px。

## 布局与断点

| 断点 | 布局 |
|---|---|
| > 1024px | 三栏：笔记列表 260px / 编辑器自适应 / 预览 45% |
| ≤ 1024px | 列表收进抽屉，顶部按钮唤起 |
| ≤ 768px | 编辑与预览二选一（`编辑 | 预览` 切换） |

预览纸张 `max-width: min(677px, 100%)`——**677px 是公众号正文的实测阅读宽度**，对齐这个数值，PC 上看到的折行位置才接近手机上发布后的样子。

## 组件

**胶囊按钮**：高 36px、圆角 18px、13px 中等字重、描边 `--border`。主按钮填充绿色白字，次按钮浅灰底。

**笔记项**：标题单行截断、摘要两行截断（`-webkit-line-clamp`）、右下角时间。选中态用绿底浅色 + 左侧绿色竖条。

**Toast**：顶部居中、深色半透明底、圆角 24px、3 秒自动消失。成功用绿点，失败用红点——不靠颜色区分文案，靠文字本身说清楚。

**代码块**：`#2B2B2B` 深灰底、圆角 6px、横向滚动。不用纯黑，长文里纯黑对比过强。

## 动效

只保留有信息量的动效：抽屉 250ms `ease`、按钮与卡片 150ms、toast 300ms 位移淡入。不做加载骨架、不做页面转场——这是一个工具，不是展示页。

## 可访问性

- 正文对比度 `#111` on `#FFF` ≈ 18:1，远超 WCAG AA
- 次要文字 `#888` 只在 12px 以上、且承载非关键信息
- 所有图标按钮带 `title`，交互元素最小点击区 32px
- 不用「颜色 + 无文案」表达状态，避免色觉障碍用户丢失信息
